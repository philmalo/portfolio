Site statique bâti avec [Astro](https://astro.build), qui m’a servi de terrain
pour apprendre le framework. Le contenu vit dans des Content Collections en
Markdown et en JSON, validées par des schémas Zod, et le routage bilingue
français/anglais est généré à partir d’une seule route dynamique.

Le terminal animé est la seule île React du site. Tout le reste est du HTML
statique et du CSS fait main, sans framework CSS, jusqu’à l’effet d’écran
cathodique.
