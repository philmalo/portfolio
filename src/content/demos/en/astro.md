A static site built with [Astro](https://astro.build), which I used as a
playground to learn the framework. Content lives in Markdown and JSON Content
Collections validated by Zod schemas, and the bilingual French/English routing
is generated from a single dynamic route.

The animated terminal is the site’s only React island. Everything else is static
HTML and hand-written CSS, with no CSS framework, right down to the CRT screen
effect.
